# 次元收纳盒 产品功能

> 把每一份热爱都收进谷里。本地优先的个人多坑记录与统计工具。

## 核心模块

### 1. 首页
- 每日问候与头像展示
- 今日待办 / 倒计时（最近提醒）
- 数据速览：本月花费、净花费、抽卡数、阅读字数
- 模块入口：游戏、追星、小说、周边
- 最近动态时间线
- 右下角快捷添加浮钮

### 2. 游戏
- 游戏库管理：添加、编辑、归档、删除
- 状态筛选与搜索
- 游戏详情页 Tab：概览 / 剧情 / 抽卡 / 图鉴 / 统计 / 设置
- 剧情记录：主线 / 活动 / 卡面 / 其他，含剧透折叠
- 抽卡记录：卡池、抽数、出货明细、垫抽与保底统计
- 卡面图鉴：拥有/未拥有、稀有度
- 抽卡统计：出货率、UP 命中率、歪率、平均出货抽数、月度趋势

### 3. 追星
- 追星对象管理：单人 / 团体 / CP / 虚拟偶像
- 详情页 Tab：概览 / 物料 / 行程 / 应援 / 图频 / 统计
- 物料记录：MV、综艺、直播、影视等
- 行程 / 活动：演唱会、见面会、打歌等，含票价与现场 repo
- 应援：投票、集资、生日应援、冲榜等
- 图频：官方图、饭拍、直拍、表情包收藏

### 4. 小说
- 小说库管理：想读 / 在读 / 已读 / 弃文 / 搁置 / 重读
- 详情页 Tab：概览 / 阅读 / 笔记 / 摘抄 / 角色 / 书单 / 统计
- 阅读记录：章节进度、字数、时长
- 笔记 / 书评：短评、长评、人物分析、CP 分析、剧透折叠
- 摘抄：内容、出处、收藏/最爱
- 角色 / CP：性格、结局、好感度

### 5. 周边
- 周边库管理：拥有 / 重复 / 心愿 / 已出 / 出借 / 丢失 / 损坏
- 详情页 Tab：概览 / 购买 / 出物 / 收纳 / 统计
- 订单记录：待付款 / 待补款 / 待发货 / 已到货等状态
- 出物 / 回血：计算净回血、自动更新周边状态
- 收纳：位置、展示/防潮/避光/外借

### 6. 全局搜索
- 跨模块关键词搜索
- 范围筛选：全部 / 游戏 / 追星 / 小说 / 周边 / 提醒
- 搜索结果按模块分组，点击进入对应详情

### 7. 提醒
- 提醒列表：全部 / 今天 / 即将 / 已过 / 已完成
- 新建提醒：模块、类型、日期时间、优先级、备注
- 一键标记完成

### 8. 数据统计
- 时间范围：本周 / 本月 / 今年 / 全部
- 总览卡片：总花费、回血、净花费、抽卡、阅读、周边等
- 趋势图表：月度花费、月度抽卡、月度阅读
- 分布：周边 IP 分布、周边类型分布

### 9. 我的
- 个人资料：昵称、头像、签名
- 模块管理：开关底部导航模块
- 外观：浅色 / 深色 / 跟随系统，隐藏金额
- 隐私锁：4-6 位数字 PIN
- 数据管理：JSON 导出 / 导入、回收站（恢复 / 彻底删除）、清空数据
